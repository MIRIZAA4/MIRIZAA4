# משחקי משפחה — אתר משחקים על המסך

אתר סטטי (HTML/CSS/JS, בלי שרת) עם משחקים למשפחה, מותאם לציבור שומר תורה ומצוות: חדר בריחה על המסך, חידון לשבע ברכות, משחק משימות בקבוצות ומשפט משפחתי קומי.

## מבנה
- `index.html` — דף הבית: קטגוריות ורשימת משחקים.
- `game.html#<id>` — דף משחק (פרטים, טעימה, קוד פתיחה).
- `play/*.html` — המשחקים עצמם (כל משחק קובץ אחד).
- `assets/` — עיצוב משותף, נתוני המשחקים, מנגנון הגישה (קודי פתיחה) ועזרים.
- `games/` — מסמכי התוכן והרעיונות (כולל ארכיון של טיוטות קודמות).
- `dist/` — עותק לפרסום (דף הבית בלי עטיפת מסמך, לפרסום כ־Artifact).

## הרצה מקומית
```
python3 -m http.server 8765
```
ואז לפתוח `http://localhost:8765/`.

## קודי פתיחה (זמני, עד חיבור סליקה)
מוגדרים ב־`assets/access.js`. הקוד `MISHPACHA` פותח את כל המשחקים.
