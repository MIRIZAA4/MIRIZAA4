# בת הכפר – רומן

רומן קלאסי לציבור החרדי, 43 פרקים (כ־132,000 מילה, כ־600 עמודים בפורמט A5).
ליטא, בשנים שלפני המלחמה. בת כפר נישאת לגביר אלמן מקובנה, אב לילדה בת שנתיים וחצי. העלילה נמשכת שנה אחת, מאלול עד סוכות, ומסתיימת בלידה ובברית.

## קבצים
- `בת הכפר.docx` – הספר המלא בקובץ Word אחד (A5, גופן David, מימין לשמאל).
- `chapters/01.md` … `chapters/43.md` – הפרקים, קובץ לכל פרק.
- `00-תכנון-הספר.md` – דמויות, מקומות, עלילה ויומן רציפות.
- `01-כללי-שפה-וסגנון.md` – כללי הלשון הנקייה שהספר נכתב לפיהם.
- `02-מתווה-פרקים-מפורט.md` – מתווה מפורט לכל פרק.
- `notes/` – הערות רציפות לכל פרק.

## בנייה מחדש של קובץ ה־Word
```
pip install python-docx
python3 book/build_docx.py
```
