# בת הכפר – מהדורה מוקפדת

העתק של הספר "בת הכפר" (המקור נשאר בתיקייה `book` בלי שינוי).
ההבדל היחיד: במהדורה הזאת אין שום דיבור ישיר בין אישה או בחורה לבין גבר שאינו מן המשפחה. הכלל המלא, החריגים והדרך שבה הדברים מועברים כתובים ב־`04-כלל-ההפרדה.md`.

- `בת הכפר – מהדורה מוקפדת.docx` – הספר המלא בקובץ Word.
- `chapters/` – 43 הפרקים.
- `notes-v2/` – רשימת השינויים בכל פרק לעומת המקור.

בנייה מחדש: `python3 book-v2/build_docx.py`
